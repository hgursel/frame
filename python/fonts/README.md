# Report fonts

Licensed under SIL OFL 1.1; see [OFL.txt](OFL.txt). These assets are independent of Frame’s code license.

Upstream: https://github.com/liberationfonts/liberation-fonts

Bundled to keep PDF typography reproducible and offline on supported hosts.
ReportLab embeds subsets into generated PDFs. No host font installation or runtime font download is required.
